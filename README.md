# Kimia Farma Business Performance Analytics 2020–2023

## Project Overview

Project-Based Internship Analisis Kinerja Bisnis Kimia Farma Tahun 2020–2023.

Project ini bertujuan untuk menganalisis performa bisnis Kimia Farma berdasarkan data transaksi, produk, kantor cabang, dan inventory selama periode 2020–2023.

## Objectives

- Menganalisis perkembangan transaksi, nett sales, dan nett profit.
- Mengidentifikasi provinsi dengan performa bisnis tertinggi.
- Menganalisis performa cabang berdasarkan rating.
- Mengidentifikasi produk dengan nett sales dan nett profit tertinggi.
- Menganalisis hubungan persentase diskon dengan nett sales.

## Dataset

Data yang digunakan terdiri dari:

- `kf_final_transaction`
- `kf_inventory`
- `kf_kantor_cabang`
- `kf_product`

Periode data: **2020–2023**

## Tools

- Google BigQuery
- SQL
- Google Looker Studio
- GitHub

## Analysis

Analisis dilakukan menggunakan SQL di Google BigQuery, meliputi:

1. Data Overview
2. Analysis Table Creation
3. KPI Analysis
4. Year-over-Year Analysis
5. Province Analysis
6. Branch Analysis
7. Product Analysis
8. Discount Analysis

## Key Findings

- Kinerja bisnis Kimia Farma relatif stabil selama 2020–2023.
- Tahun 2022 mencatat nett sales dan nett profit tertinggi.
- Jawa Barat menjadi provinsi dengan kontribusi terbesar terhadap transaksi dan nett sales.
- Terdapat gap antara rating cabang dan rating transaksi pada beberapa cabang.
